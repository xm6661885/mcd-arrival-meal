# 麦麦落地补给 · mcd-arrival-meal

> 下了高铁就有热乎的麦当劳。

坐了几个小时高铁或飞机，下车后最不想做的事就是在站内麦当劳排队。这个 Skill 按你的**到站或落地时间**，在车站、机场附近的麦当劳**提前预约取餐**：

- 自动算"到达 + 步行"后的取餐时间，并对上门店真实的预约时段（早餐、午餐切换的空档会自动顺延，并告诉你要等几分钟）；
- 按那个时段的菜单选餐（早上 7 点到站，推荐的是早餐菜单）；
- 列出同一车站几家门店的实付价格，到站前查取餐码；
- **晚点了**会根据订单状态告诉你：取消后重订，还是联系门店。

## 真实运行示例

12:05 到广州南站，下车走到门店约 8 分钟，想吃麦辣鸡腿汉堡三件套：

```
到达 2026-10-11 12:05，按步行时间预计 2026-10-11 12:13 可到门店。

1. 麦当劳广州南站三楼A23检票口上方餐厅（55m，营业 06:00-23:00）
   预约取餐：2026-10-11 12:13（午餐时段）
   麦辣鸡腿汉堡三件套×1 实付 ¥47.00（取餐方式：堂食/外带）
2. 广州南站地铁D出口快捷小站（62m，营业 06:00-23:00）
   预约取餐：2026-10-11 12:13（午餐时段）
   麦辣鸡腿汉堡三件套×1 实付 ¥49.00（取餐方式：堂食/外带）
3. 麦当劳广州南站三楼A9检票口上方餐厅（63m，营业 06:00-23:00）
   预约取餐：2026-10-11 12:13（午餐时段）
   麦辣鸡腿汉堡三件套×1 实付 ¥49.00（取餐方式：堂食/外带）

确认门店、餐品和取餐方式后，用 order 子命令带 --confirm 下单。
```

同一个车站的三家门店，同一份套餐，实付相差 ¥2。

## 目标用户

- 高铁、飞机通勤和出差的人
- 中转时间短、想下车就拿到餐的旅客
- 帮家人订"到站餐"的人

## 安装

1. 在 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 申请 MCP Token。
2. 参考 `mcp-config.example.json` 在 Agent 里配置 `mcd-mcp`。
3. 导入本仓库作为 Skill（入口为 `SKILL.md`）。
4. 如需直接运行脚本：`export MCD_MCP_TOKEN=你的Token`（Python 3.9+，无第三方依赖）。

## 使用示例

对 Agent 说：

- "我坐 G1234 明天 12:05 到广州南站，帮我订一份麦辣鸡腿堡套餐，下车就去拿"
- "明早 7:40 落地深圳机场，有什么早餐可以预约？"
- "高铁晚点 40 分钟，我那单麦当劳怎么办？"

命令行：

```bash
python3 scripts/arrival.py plan --city 深圳市 --keyword 深圳宝安国际机场 --arrive "2026-10-11 07:40"
python3 scripts/arrival.py delay --order <订单号> --arrive "2026-10-11 12:50"
```
